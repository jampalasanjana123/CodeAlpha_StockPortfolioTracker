
# CodeAlpha Stock Portfolio Tracker

## About the Project
This is a simple Python project developed as part of
the CodeAlpha task. It calculates total stock investment
using predefined stock prices.

## Features
- Accepts stock names and quantities from users
- Uses a Python dictionary to store stock prices
- Calculates individual stock investment values
- Displays total portfolio investment
- Saves results to a text file
- Handles invalid numeric input

## Technologies Used
- Python 3
- Dictionary
- Input and Output
- Loops and Conditional Statements
- Basic Arithmetic
- File Handling

## How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command:

   python stock_tracker.py
